# DS 算法题学习大纲

[在线页面](https://futabaly.github.io/ds/algorithm-outline/)

当前包含 8 个专题、知识点 / 解题过程 / 历年真题 / 公式速查四个环节，支持目录搜索及可分享的专题链接。已收录 **8 道真题**：2009/42、2010/42、2011/42、2012/42、2013/41、2015/41、2018/41、2019/41。每题包含基础解、优化解、分步示例、复杂度与边界自查。本路线是学习组织方式，不是官方考试大纲，也不声称考频排名。

## 本地运行

网页零运行依赖。校验需要 Node.js 与支持 C++17 的 `g++`（GitHub Ubuntu runner 自带）。运行 `npm ci`、`npm run check`、`npm run web:build`；用任意静态服务器打开 `dist/`。通过 `projects.json` 接入 DS 门户和现有 Pages 工作流。

- `topics.js`：专题、知识要点、解题路线与有条件的复杂度结论。
- `app.js`：搜索、栏目切换、URL 状态。
- `index.html` / `style.css`：响应式页面。
- [后续补充计划](PLAN.md)：下一轮的边界和批次。

内容结构参考用户指定的 CO 数字编码实验室。后续保持明亮卡片、深色页头与分步学习体验。

## 题解约定

每题按「暴力解法 → 瓶颈分析 → 优化解法 → 两解对照」展开，两种解法分别说明思路、代码、时间 / 空间复杂度与适用条件。暴力解不满足约束或基础解已最优时明确说明。

## 验证与来源

`npm run check` 直接编译网页展示的两种 C++ 解法，并执行链表边界及不可变性检查、3,720 组循环移动检查、6,000 组中位数与主元素对照检查。下载文件 `solutions.hpp` 与展示代码来自同一份数据。

[来源与纠错记录](SOURCES.md)。题意为概述、解析为本站整理；不冒称官方答案，不承诺评分。后续题目仍在分批补充。

第二批测试包含 486 组共同后缀组合、3,240 组按绝对值去重与缺失正整数输入、0—80 长度的两种重排解法。链表题校验结点身份与尾指针；共享后缀校验不修改连接，删除题检查保留首次出现的原结点。
